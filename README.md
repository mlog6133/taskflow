# taskflow
## Description
TaskFlow is a web-based task management app for small teams. It helps teams manage tasks, assign responsibilities, and track progress in real-time.

## Features
- User Authentication
- Task Creation
- Task Assignment
- Status Updates
- Dashboard Overview
- Collaboration Tools (comments/notifications)

## Technologies Used
- React.js (Frontend)
- Node.js + Express (Backend)
- MongoDB (Database)
- Firebase (Authentication)
